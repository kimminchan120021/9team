# Naval Counter-UAS Decision Support Simulator

## 프로젝트 소개
본 프로젝트는 해군 함정의 대드론 대응 절차를 교육용으로 시각화하는 의사결정 시뮬레이터이다.

## 개발 목적
가상의 드론 접근 상황에서 탐지, 식별, 경계태세 전환, 대응 절차 및 결과 기록 과정을 프로그램으로 구현한다.

## 주요 기능
1. 가상 드론 접근 상황 입력
2. 탐지 및 식별 상태 표시
3. 경계태세 변화 시각화
4. 교육용 대응 절차 시뮬레이션
5. 시뮬레이션 결과 및 판단 이력 출력

## 개발 환경
- Python
- Git / GitHub
- 오픈소스 GUI 라이브러리 (추후 선정)

## 팀 구성
- 팀장: 알고리즘 구조 설계 및 프로젝트 통합
- 팀원 A: 입력 및 탐지 화면 구현
- 팀원 B: 상태 전환 및 결과 기록 기능 구현# 9team
